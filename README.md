# Golang Examples 🐹

Bem-vindo ao **golang-examples**!
Este repositório é o meu cantinho pessoal de estudos e aprendizado da linguagem **Go (Golang)**.

Aqui eu organizo exemplos simples e diretos, **um conceito por pasta**, para fixar os fundamentos da linguagem.

Cada pasta tem um `main.go` pronto para rodar com:

`go run`

Ou simplesmente:

`go run main.go`

## 📋 Conceitos já explorados

- **Variáveis e constantes**
- **Tipos básicos e conversões**
- **Operadores**
- **Estruturas de controle (if, for, switch, break/continue)**
- **Slices e Maps**
- **Structs (com métodos e embedding)**

Estou adicionando mais exemplos aos poucos, sempre priorizando clareza e simplicidade, ideal para quem está começando ou revisando o básico do Go.

## 🛠️ Como usar este repositório

1. Clone o projeto:
`git clone https://github.com/tiagollopes/golang-examples.git`
`cd golang-examples`

2. Escolha uma pasta (exemplo: structs):
`cd structs`

3. Execute o exemplo:
`go run`
